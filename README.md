# Danial Mohazab — Portfolio

A static, single-page portfolio for [dmohazab.github.io](https://dmohazab.github.io/). It uses semantic HTML, CSS, and a small JavaScript enhancement for the footer year. No build step or package installation is required.

## Preview locally

From the repository root:

`python3 -m http.server 8000`

Open [http://localhost:8000](http://localhost:8000). GitHub Pages serves the same files from the repository root.

## Content and assets

- Main copy and metadata: `index.html`
- Layout and design tokens: `css/style.css`
- Optimized project images, favicon, and social preview: `images/`

The current work description reflects Danial's provided high-level summary. Project descriptions are limited to the existing site and public repositories. The old résumé link was removed because its PDF was outdated.
